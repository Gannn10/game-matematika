# 🧮 Interactive Math Game (Python)

Aplikasi permainan edukatif matematika interaktif yang dibangun menggunakan bahasa pemrograman **Python**[cite: 7]. Proyek ini dirancang menggunakan prinsip arsitektur terstruktur (*Modular Architecture*), memisahkan bagian logika permainan (*Core*), manajemen data (*Data*), serta antarmuka pengguna (*View*) secara bersih[cite: 7].

## ✨ Fitur Utama
* **Structured Architecture:** Menerapkan pemisahan folder yang rapi (`Core`, `Data`, `View`)[cite: 7] untuk menjaga keterbacaan kode (*clean code*).
* **Interactive Gameplay:** Logika permainan matematika dinamis yang diatur melalui modul inti (`Game.py`)[cite: 7].
* **Data Management:** Pengelolaan skor atau data pendukung permainan secara terpusat (`Data.py`)[cite: 7].
* **Clean Interface:** Tampilan antarmuka berbasis teks/konsol yang terorganisir dengan baik (`View.py`)[cite: 7].

## 🛠️ Tech Stack
* **Language:** Python[cite: 7]
* **Architecture:** Modular / MVC Pattern
